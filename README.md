## About This Repository

This repository contains structured, beginner-friendly, and interview-focused revision notes for the **Prime 2.0 : Complete AI/ML Job Preparation** program. 

Every note is crafted to eliminate lecture fluff and focus 100% on:
- **Intuitive Mental Models**: Real-world analogies (traffic lights, egg cartons, hotel doors, blenders) to understand complex concepts before looking at syntax.
- **Formal Interview Definitions**: Crisp, textbook definitions formatted in callout boxes (`> [!NOTE]`) ready for technical interviews.
- **Clean Python Implementations**: Commented, idiomatic code snippets (without unnecessary boilerplate).
- **Quick Interview Q&A (Cheatsheets)**: High-yield questions and direct answers covering common traps and gotchas.

## Course Curriculum Overview

The notes in this repository follow the official Prime 2.0 syllabus:

1. **Python & Data**
   - Python Fundamentals, Control Flow & Functions
   - Built-in Data Structures (Strings, Lists, Tuples, Dictionaries, Sets)
   - Object-Oriented Programming (OOP) & The 4 Pillars
   - File I/O, Exception Handling & List Comprehensions
   - NumPy (Arrays, Broadcasting, Vectorization, Statistics)
   - Pandas, Data Cleaning, Matplotlib & Seaborn
2. **Machine Learning**
   - Mathematics & Statistics for ML (Linear Algebra, Calculus, Probability)
   - Supervised Learning (Regression, Classification, SVM, Trees, Ensembles)
   - Unsupervised Learning (Clustering, PCA, Dimensionality Reduction)
   - Feature Engineering, Preprocessing & Evaluation Metrics
3. **Deep Learning**
   - Artificial Neural Networks (ANN), Forward & Backpropagation
   - Optimizers, Loss Functions & Regularization
   - Convolutional Neural Networks (CNN) for Computer Vision
   - Recurrent Neural Networks (RNN & LSTM) for Sequence Data
   - Transformers & Attention Mechanism
4. **Generative AI (GenAI)**
   - Foundation Models & Large Language Models (LLMs)
   - Prompt Engineering & Context Windows
   - Retrieval-Augmented Generation (RAG) & Vector Databases
   - Model Fine-Tuning & Quantization
5. **AI Engineering Stack**
   - Vector Databases (Chroma, Pinecone, FAISS)
   - Frameworks (LangChain, LlamaIndex)
   - Model Deployment, Docker & FastAPI
6. **Industry Grade Projects**
   - End-to-end production-grade AI & Data Science applications
